# ClinicalShield

A Multi-Layer Defense Framework for Detecting and Neutralizing Indirect Prompt
Injection Attacks in RAG-Based Clinical Decision Support Systems.

## Four Modules
1. Encoding-Aware Ingestion (Base64, hex, Unicode, Leetspeak)
2. PubMedBERT Dual-Encoder Detection + Attention Token Localization
3. Semantic Intent Verification for RAG
4. Utility-Preserving Sanitization with CEPS metric

## Hardware
Google Colab L4 GPU (24GB VRAM)
